GrowthB API

REST API untuk aplikasi pengambilan keputusan pelaku UMKM. Dibangun dengan Laravel 13 + Sanctum authentication.

BASE URL http://localhost:8000/api
Total Endpoint
22
6 public · 16 protected
AI Engine
Gemini 2.5 Flash
Analisa otomatis tiap 14 hari

Member

Sistem membership berbasis QR code. Pelanggan scan QR → input nomor HP → kunjungan tercatat otomatis.

GET /member/scan/{token} PUBLIC Validasi QR scan ▼

Dipanggil frontend saat pelanggan membuka link QR. Tidak butuh auth.

{
  "data": {
    "bisnis_id": 1,
    "bisnis_nama": "Warung Makan Bu Sari",
    "member_token": "abc123..."
  }
}
POST /member/checkin/{token} PUBLIC Submit nomor HP pelanggan ▼
FieldTipeKeterangan
member_phone wajibstringNomor HP pelanggan, format E.164 direkomendasikan
 
{
  "data": {
    "member_phone": "+6281234567890",
    "member_count": 5,
    "reward": {
      // null jika pemilik belum set reward_threshold
      "is_eligible": false,
      "kunjungan_saat_ini": 5,
      "kunjungan_dibutuhkan": 10
    }
  }
}
POST /member/reward/set Atur threshold reward ▼
🔐 Bearer token · Harus diatur sebelum fitur reward bisa digunakan
⚠️ Selama reward_threshold belum diatur, endpoint GET /member/reward akan mengembalikan error 422.
FieldTipeKeterangan
reward_threshold wajibintegerJumlah kunjungan minimum untuk dapat reward. Min. 1
 
{
  "message": "Reward threshold berhasil diatur",
  "data": { "reward_threshold": 10 }
}
GET /member/reward List member yang layak reward ▼
⚠️ Akan error 422 jika reward_threshold belum diatur di pengaturan bisnis.
{
  "reward_threshold": 10,
  "total": 3,
  "data": [
    { "id": 1, "member_phone": "+6281234567890", "member_count": 12 }
  ]
}

Analisa AI

Analisa bisnis otomatis menggunakan Gemini 2.5 Flash. Berjalan per siklus 14 hari dihitung dari tanggal mulai bisnis. Setiap siklus hanya bisa di-generate sekali, dan hanya jika semua 14 hari data harian sudah terisi.

GET /analisa/status Cek status siklus saat ini ▼

Gunakan endpoint ini di frontend untuk menampilkan progress pengisian data dan tombol generate analisa.

{
  "data": {
    "periode": {
      "dari": "2024-07-01",
      "sampai": "2024-07-14",
      "siklus_ke": 3
    },
    "jumlah_data_terisi": 11,
    "jumlah_data_dibutuhkan": 14,
    "data_lengkap": false,
    "sudah_dianalisa": false,
    "bisa_generate": false
    // bisa_generate = true hanya jika data_lengkap && !sudah_dianalisa
  }
}
POST /analisa/generate Generate analisa AI ▼
🔐 Bearer token · Tidak perlu body — periode ditentukan otomatis oleh sistem
⚠️ Akan ditolak (422) jika: data harian belum lengkap 14 hari, atau siklus ini sudah pernah dianalisa.
// Success (201)
{
  "message": "Analisa berhasil digenerate",
  "data": {
    "periode": { "dari": "2024-07-01", "sampai": "2024-07-14" },
    "eval": { "id": 5, "pesan": "Selama periode ini...", "created_at": "..." },
    "plan": { "id": 6, "pesan": "Rekomendasi: 1. ...", "created_at": "..." }
  }
}

// Error: data belum lengkap (422)
{ "message": "Data harian belum lengkap. Masih kurang 3 hari input data (periode 2024-07-01 s/d 2024-07-14 harus terisi semua 11/14 hari)." }

// Error: sudah dianalisa (422)
{ "message": "Periode ini (2024-07-01 s/d 2024-07-14) sudah pernah dianalisa. Analisa berikutnya tersedia pada siklus berikutnya." }
GET /analisa/latest Eval + plan terbaru sekaligus ▼ 
{
  "data": {
    "eval": { "id": 5, "pesan": "...", "created_at": "..." },
    "plan": { "id": 6, "pesan": "...", "created_at": "..." }
  }
}
