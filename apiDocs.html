Analisa AI

Analisa bisnis otomatis per siklus 14 hari menggunakan Gemini 2.5 Flash. Orientasi analisa mengikuti roadmap aktif — jika tidak ada, fallback ke tujuan bisnis dari profil.

💡Orientasi AI: Evaluasi dan rekomendasi selalu diarahkan sesuai target. Jika ada roadmap aktif, AI menilai seberapa jauh performa mendukung tiap target roadmap. Jika tidak ada roadmap, AI mengacu pada tujuan_bisnis yang diisi saat daftar bisnis.
GET/analisa/statusStatus siklus saat ini▼

Gunakan endpoint ini di FE untuk menampilkan progress bar pengisian data dan mengaktifkan tombol generate. 

{
  "data": {
    "periode": { "dari": "2024-07-01", "sampai": "2024-07-14", "siklus_ke": 3 },
    "jumlah_data_terisi": 11,
    "jumlah_data_dibutuhkan": 14,
    "data_lengkap": false,
    "sudah_dianalisa": false,
    "bisa_generate": false  // true hanya jika data_lengkap && !sudah_dianalisa
  }
}
POST/analisa/generateGenerate analisa AI▼
🔐Tidak perlu body — periode ditentukan otomatis dari siklus 14 hari bisnis.
⚠️Ditolak 422 jika: data harian <14 hari, atau siklus ini sudah pernah dianalisa.

Roadmap

🎯Peran roadmap dalam AI: Semakin spesifik target yang diisi (target_metrik, target_nilai, target_tanggal), semakin terarah analisa dan rekomendasi yang dihasilkan AI.

What If

Simulasi skenario bisnis menggunakan Gemini 2.5 Flash. Batas 3 prediksi per hari, reset tiap tengah malam. Analisa selalu berorientasi pada roadmap aktif — jika tidak ada, fallback ke tujuan bisnis.

🎯Orientasi What If: Sama seperti analisa, hasil prediksi diarahkan untuk mendukung pencapaian roadmap aktif atau tujuan bisnis. Semakin detail roadmap, semakin relevan rekomendasinya.
